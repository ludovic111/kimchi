# Working with other apps

Generated by `kimchi-cli docs` from kimchi's own tables. Do not edit by hand.

Coming from another editor? kimchi opens its projects, uses its looks and LUTs, and can take its keyboard shortcuts. The first-run setup (Help › Set up kimchi…) does all of it for the app you choose; `app.onboarding` lists what it finds on your computer. Commands: `project.importFrom`, `project.exportTo`, `looks.import`, `app.keymaps` (see [COMMANDS.md](COMMANDS.md)).

## Video editors

### Premiere Pro (Adobe)

- **kimchi opens:** Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **kimchi writes for it:** Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **Keyboard:** Premiere Pro's layout (`shortcuts.keymap` = `premiere`). Add Edit (⌘K) splits, S turns snapping on and off, \ fits the sequence; the command palette has no key here.
- **Bring a project over:** In Premiere Pro, select the sequence in the Project panel and choose File › Export › Final Cut Pro XML…. Open that .xml in kimchi (Home › Open from another editor).
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for Premiere Pro… (Final Cut Pro 7 XML). In Premiere Pro, choose File › Import and pick the .xml.
- **Looks:** Lumetri Color presets (.prfpset) and the .cube LUTs in Lumetri's Input LUT and Creative Look menus: kimchi reads both.
- **Plugins:** Premiere Pro plugins are built on Adobe's own SDK and only run in Adobe's apps. kimchi runs lsuite plugins (ask your agent to build one) and frei0r filters.

### Final Cut Pro (Apple)

- **kimchi opens:** Final Cut Pro XML (FCPXML)
- **kimchi writes for it:** Final Cut Pro XML (FCPXML)
- **Keyboard:** Final Cut Pro's layout (`shortcuts.keymap` = `finalcut`). Delete closes the gap as in Final Cut's magnetic timeline (Shift-Delete leaves one), ⌘B blades, comma and period nudge.
- **Bring a project over:** In Final Cut Pro, select the project in the browser and choose File › Export XML…. Open the .fcpxml (or .fcpxmld) in kimchi.
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for Final Cut Pro… (FCPXML). In Final Cut Pro, choose File › Import › XML….
- **Looks:** Final Cut's Custom LUT effect uses .cube files: kimchi reads the same ones.
- **Plugins:** FxPlug plugins only run in Final Cut Pro and Motion. kimchi runs lsuite plugins (ask your agent to build one) and frei0r filters.

### DaVinci Resolve (Blackmagic Design)

- **kimchi opens:** OpenTimelineIO, Final Cut Pro XML (FCPXML), Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **kimchi writes for it:** OpenTimelineIO, Final Cut Pro XML (FCPXML), Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **Keyboard:** DaVinci Resolve's layout (`shortcuts.keymap` = `resolve`). ⌘\ splits, Shift-[ and Shift-] trim to the playhead, Backspace leaves a gap and Delete closes it.
- **Bring a project over:** In Resolve, select the timeline in the Media Pool and choose File › Export › Timeline…, then pick OpenTimelineIO (.otio) or FCPXML. Open that file in kimchi.
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for DaVinci Resolve… (OpenTimelineIO). In Resolve, choose File › Import › Timeline… and pick the .otio.
- **Looks:** Resolve's LUT folder holds .cube and .3dl LUTs: kimchi reads them as they are.
- **Plugins:** Resolve's OpenFX plugins, Fusion macros and DCTL don't run in kimchi. kimchi runs lsuite plugins (ask your agent to build one) and frei0r filters.

### CapCut (ByteDance)

### Media Composer (Avid)

- **kimchi opens:** CMX 3600 EDL
- **kimchi writes for it:** CMX 3600 EDL
- **Keyboard:** Media Composer's layout (`shortcuts.keymap` = `avid`). A and S go to the previous and next edit, Z lifts and X extracts, H adds an edit, ⌘3 opens the command palette.
- **Bring a project over:** In Media Composer, open Tools › List Tool, choose CMX 3600 and save an EDL of the sequence. Open the .edl in kimchi; the media is found by its file name (point kimchi at the folder if it asks).
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for Media Composer… (EDL), then import the EDL in Media Composer.
- **Looks:** Media Composer's LUTs are .cube files: kimchi reads them.
- **Plugins:** AVX plugins only run in Media Composer.

### VEGAS Pro (MAGIX)

- **kimchi opens:** Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **kimchi writes for it:** Final Cut Pro 7 XML (Premiere XML), CMX 3600 EDL
- **Keyboard:** VEGAS Pro's layout (`shortcuts.keymap` = `vegas`). S splits, Q loops, F8 snaps, ↑ and ↓ zoom, Z and X mute and solo the track; Ctrl+Q adds an audio track there, so quit from the menu.
- **Bring a project over:** In VEGAS Pro, choose File › Export › Final Cut Pro 7 / DaVinci Resolve (*.xml)…, and open that .xml in kimchi.
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for VEGAS Pro… (Final Cut Pro 7 XML), then File › Import › Final Cut Pro 7 / DaVinci Resolve (*.xml) in VEGAS.
- **Looks:** VEGAS's LUT filter uses .cube files: kimchi reads them.
- **Plugins:** VEGAS's plugins don't run in kimchi. kimchi runs lsuite plugins (ask your agent to build one) and frei0r filters.

### Kdenlive (KDE)

- **Keyboard:** Kdenlive's layout (`shortcuts.keymap` = `kdenlive`). Shift-R cuts the clip, ( and ) trim to the playhead, G adds a guide, Ctrl+Enter renders.
- **Bring a project over:** In Kdenlive, choose File › Export › OpenTimelineIO and open the .otio in kimchi (kimchi doesn't read .kdenlive files yet).

- **Looks:** Kdenlive's LUT filter takes .cube files and its Hald CLUT filter images: kimchi reads both.
- **Plugins:** Kdenlive's frei0r effects run in kimchi when the frei0r plugins are installed (the frei0r-plugins package).

## Motion graphics and compositing

### After Effects (Adobe)

- **kimchi opens:** —
- **kimchi writes for it:** —
- **Bring a project over:** After Effects projects can't be read outside After Effects. Render the composition (ProRes 4444 keeps transparency) and import it; for new work, kimchi's Motion Studio has layers, keyframes, expressions, masks, effects and 3D.
- **Send a cut back:** Export from kimchi as ProRes 4444 or a PNG sequence and import it in After Effects.
- **Looks:** Lumetri presets (.prfpset) and .cube LUTs work in kimchi too.
- **Plugins:** After Effects plugins are built on Adobe's own SDK and only run in Adobe's apps. kimchi's Studio has its own effects, and it runs lsuite plugins and frei0r filters.

### Nuke (Foundry)

- **kimchi opens:** OpenTimelineIO
- **kimchi writes for it:** OpenTimelineIO
- **Bring a project over:** Export the timeline from Nuke Studio or Hiero as OpenTimelineIO and open it in kimchi.
- **Send a cut back:** In kimchi, open the ⋯ menu in the top bar and choose Export project for Nuke…, then import the .otio in Nuke Studio or Hiero.
- **Looks:** Nuke's .cube, .3dl, .csp, .spi1d and .spi3d LUTs work in kimchi as they are.
- **Plugins:** Nuke's plugins (OpenFX and NDK) don't run in kimchi. kimchi runs lsuite plugins (ask your agent to build one) and frei0r filters.

## Photos and colour

### Lightroom and Camera Raw (Adobe)

- **kimchi opens:** —
- **kimchi writes for it:** —
- **Bring a project over:** Your photo presets become looks: import the .xmp or .lrtemplate files (Looks › Import) and use them on any clip.
- **Send a cut back:** kimchi's looks can be saved as .cube LUTs, which Lightroom's profiles don't take; use the LUT in Premiere or Photoshop.
- **Looks:** Develop presets (.xmp, .lrtemplate): exposure, contrast, highlights, shadows, whites, blacks, white balance, vibrance, saturation, sharpening and vignette carry over.

## Project and timeline formats

| Format | Files | Used by | Open | Write | Notes |
| --- | --- | --- | --- | --- | --- |
| OpenTimelineIO (`otio`) | .otio .otioz .otiod | DaVinci Resolve, Premiere Pro, Media Composer, Kdenlive, Nuke | good | good | The open interchange format of the Academy Software Foundation: every track, clip, gap, transition and marker. |
| Final Cut Pro XML (FCPXML) (`fcpxml`) | .fcpxml .fcpxmld | Final Cut Pro, DaVinci Resolve, iMovie, Premiere Pro | good | good | Final Cut Pro's own interchange (versions 1.6 to 1.13), also read and written by DaVinci Resolve. |
| Final Cut Pro 7 XML (Premiere XML) (`xmeml`) | .xml | Premiere Pro, DaVinci Resolve, VEGAS Pro, Media Composer | good | good | What Premiere Pro exports with File › Export › Final Cut Pro XML; read by Resolve and most editors. |
| CMX 3600 EDL (`edl`) | .edl | Premiere Pro, DaVinci Resolve, Media Composer, Final Cut Pro, VEGAS Pro | basic | basic | The oldest common list of cuts: one video track and its sound, reel names and timecodes, dissolves and wipes. |
| Kdenlive project (`kdenlive`) | .kdenlive | Kdenlive | — | — | Not read or written yet: Kdenlive's MLT project, with its frei0r filters kept as frei0r plugins. |
| Shotcut / MLT XML (`mlt`) | .mlt | Shotcut, Kdenlive | — | — | Not read or written yet: Shotcut's project file (MLT XML), with its frei0r filters kept as frei0r plugins. |
| OpenShot project (`openshot`) | .osp | OpenShot | — | — | Not read or written yet: OpenShot's JSON project: clips, keyframed position, scale, rotation, alpha and volume, transitions. |
| Premiere Pro project (`prproj`) | .prproj | Premiere Pro | — | — | Not read or written yet: Premiere's own project file, read without Premiere: its sequences' cuts. For more, export Final Cut Pro XML from Premiere. |
| CapCut / JianYing draft (`capcut`) | .json | CapCut | — | — | Not read or written yet: A CapCut draft folder (draft_content.json or draft_info.json). Recent CapCut versions encrypt drafts on Windows and Mac; those can't be read. |

_basic_: the cut (clips, timing, tracks). _good_: the cut and most of what the format carries that kimchi has (transforms, opacity, volume, fades, transitions, titles, markers, speed).

## Looks and LUTs

| Format | Files | Used by | Notes |
| --- | --- | --- | --- |
| Cube LUT (1D or 3D) | .cube | DaVinci Resolve, Premiere Pro, Final Cut Pro, After Effects, CapCut, Kdenlive, Shotcut, Lightroom and Camera Raw | The common LUT format (Adobe / Resolve). Used as it is. |
| 3DL LUT | .3dl | DaVinci Resolve, Premiere Pro, Nuke | Autodesk / Lustre 3D LUT. Used as it is. |
| cineSpace LUT | .csp | DaVinci Resolve, Nuke | Rising Sun cineSpace LUT with its pre-LUT shaper. Used as it is. |
| Sony Imageworks LUT | .spi1d .spi3d | Nuke, DaVinci Resolve | OpenColorIO's own LUT files. Used as they are. |
| Hald CLUT image | .png .tif .tiff | Kdenlive, Shotcut, Lightroom and Camera Raw | A LUT stored as a picture (darktable, RawTherapee, G'MIC, ffmpeg haldclut). Used as it is. |
| Lightroom / Camera Raw preset | .xmp .lrtemplate | Lightroom and Camera Raw, Premiere Pro, After Effects | Exposure, contrast, highlights, shadows, whites, blacks, temperature, tint, vibrance, saturation, sharpening and vignette, mapped onto kimchi's corrections. |
| Premiere Lumetri preset | .prfpset | Premiere Pro | The Basic correction and Creative sections of a Lumetri Color preset, and its LUTs when they are on this computer. |

## The assistant

The Agent panel runs one of: `lsuite`, `claude-code`, `codex`, `gemini-cli`, `anthropic`, `openai`, `gemini`, `openrouter`, `groq`, `mistral`, `deepseek`, `xai`, `together`, `fireworks`, `cerebras`, `azure-openai`, `bedrock`, `ollama`, `lmstudio`, `openai-compatible`. Settings › Agent, `agent.providers`, `agent.setProvider`. Any MCP client can drive kimchi too: `kimchi-mcp --live`.
